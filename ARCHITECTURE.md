# Архитектура системы и описание инструментов

## Общая схема пайплайна

Система обрабатывает данные последовательно, проходя через пять логических слоев.

1. **Слой загрузки.** Принимает на вход JSON-файл с фенотипом пациента и TSV-файл с аннотированными вариантами. Из фенотипа извлекаются HPO-термины, при этом признаки, помеченные как `excluded`, исключаются из анализа, так как они клинически отсутствуют у пациента.
2. **Слой фильтрации.** Отсекает варианты с высокой популяционной частотой (AF ≥ 0.01). Это позволяет убрать распространенные полиморфизмы, которые не могут быть причиной редкого заболевания.
3. **Слой фенотипического сопоставления.** С помощью библиотеки `pyhpo` вычисляется семантическое сходство между HPO-терминами пациента и HPO-терминами, ассоциированными с конкретным геном. Использование онтологии позволяет учитывать иерархические связи между симптомами.
4. **Слой оценки патогенности.** Для каждого варианта определяется вес на основе клинической значимости в базе ClinVar (патогенные варианты получают максимальный вес, доброкачественные — нулевой) и типа функционального последствия по данным Ensembl VEP.
5. **Слой итогового скоринга.** Вычисляет взвешенную сумму всех признаков (фенотип, ClinVar, VEP, редкость) и формирует ранжированный список генов-кандидатов с подробным объяснением вклада каждого признака.

## Используемые инструменты и базы данных

- **Human Phenotype Ontology (HPO)** — формализованный стандарт описания фенотипов. Используется для сопоставления симптомов пациента с известными ассоциациями генов.
- **pyhpo** — Python-библиотека для работы с онтологией HPO. Позволяет вычислять семантическое сходство между наборами терминов с учетом структуры онтологии.
- **ClinVar** — база данных клинической интерпретации генетических вариантов. Используется для присвоения веса патогенности.
- **gnomAD** — база популяционных частот. Используется для фильтрации частых вариантов и оценки редкости.
- **Ensembl VEP** — инструмент аннотации вариантов. Предоставляет информацию о типе последствия (например, missense, loss-of-function).
- **Streamlit** — фреймворк для создания интерактивного веб-интерфейса приложения.
- **pandas** — библиотека для обработки и анализа табличных данных.
